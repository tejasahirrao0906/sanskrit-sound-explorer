# Sanskrit Sound Explorer

An interactive web application developed to demonstrate the systematic classification of Sanskrit sounds.

## 📌 Experiment

**Experiment No. 7:** Pronounce and classify selected Sanskrit sounds into vowels and consonants using a simple sound chart, group them according to articulation patterns, and analyze how this systematic sound organization supports pronunciation training, language learning, and speech-processing applications.

## ✨ Features

* Sanskrit vowel classification (स्वर)
* Sanskrit consonant classification (व्यञ्जन)
* Sound pronunciation using browser Speech Synthesis
* Articulation-based consonant groups
* Ka-varga, Cha-varga, Ta-varga, Ta-varga and Pa-varga classification
* Interactive quiz
* Simple and user-friendly interface

## 🗣️ Articulation Groups

| Group  | Sounds    | Place of Articulation |
| ------ | --------- | --------------------- |
| क-वर्ग | क ख ग घ ङ | Throat                |
| च-वर्ग | च छ ज झ ञ | Palate                |
| ट-वर्ग | ट ठ ड ढ ण | Retroflex             |
| त-वर्ग | त थ द ध न | Teeth                 |
| प-वर्ग | प फ ब भ म | Lips                  |
